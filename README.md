# OmniVideo para o Claude Code

OmniVideo: roteiro, motion em código, voz clonada, legenda e publicação, do pedido ao MP4.

    claude plugin install omnivideo --marketplace pedroflp/omni-plugin

Na primeira sessão o plugin prepara o computador sozinho: abre o navegador para você entrar no OmniVideo e
liga o studio local. Precisa do Chrome e do ffmpeg instalados. Este repositório é gerado automaticamente:
as skills chegam do registro do OmniVideo a cada uso.
